# Lovable MCP compatibility

This private package preserves the versioned legacy endpoint at
`/functions/v1/mcp`. It is opt-in and is not loaded by the canonical frontend
build or by the canonical `mcp-server` deployment.

The source remains in `src/lib/mcp`, while the generated Edge Function and its
compatibility snapshot remain tracked at `supabase/functions/mcp/index.ts` and
`.lovable/mcp/manifest.json`.

```sh
npm ci --prefix integrations/lovable-mcp-compat
npm --prefix integrations/lovable-mcp-compat run verify
npm --prefix integrations/lovable-mcp-compat run generate
```

`generate` is the only command that loads `@lovable.dev/mcp-js`; it rewrites
the tracked legacy Edge Function only when the generated bytes change. Run it
only when intentionally maintaining that compatibility endpoint. Any contract
change must update the tracked manifest in the same commit; `verify` checks the
SDK version, route, ownership marker and root-build isolation.
